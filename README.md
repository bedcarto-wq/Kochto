# Кочто / «Верхние Ключи»

Пошаговая политическая песочница: независимый кандидат в городе Кочто пишет действия свободными русскими фразами, неделя разрешается бросками, пресса пишет вырезки, мир реагирует. Выборы не завершают игру — game over только смерть.

Python 3.11+, только стандартная библиотека (tkinter — для окна).

## Запуск

```bash
cd Kocto
python main.py              # окно Tkinter (если доступен), иначе консоль
python main.py --console    # консоль
python main.py --selftest   # проверка данных и генератора текстов
python main.py --playtest   # режим разработчика: A/B-выбор парсер/НС и ревизия «похоже/не похоже»
python tests/smoke_test.py  # смоук-тест: фразы, мир, соперники, 104 недели, сейв (во временной папке)
python tests/balance_sim.py # баланс: 4 бота × 6 сидов × 104 недели
```

Windows без командной строки: двойной клик по `Kocto/Запустить.bat`. Для друзей — `Kocto/КАК_ИГРАТЬ.txt`.
Сборка `.exe` (Python не нужен — он встроен): собирается автоматически при пуше в `main` — GitHub → Actions → «Сборка для Windows» → последний запуск → артефакт `Kochto-windows`. Тег `v0.2` и т.п. создаёт Release со ссылкой `Kochto-windows.zip` для друзей.

Сейвы и логи создаются при первом запуске (`Kocto/saves/`, `Kocto/data/nn/eval/`) и в git не хранятся.

## Как играть

- До 3 действий в неделю, фразой: «встретиться с пенсионерами о медицине», «митинг с рабочими о зарплатах», «дать интервью газете кочто сегодня».
- Любая другая осмысленная фраза становится «своим действием»: смысл, шанс и цена собираются из тегов (тайно, деньги, СМИ, атака, помощь, обещание, разговор, разведка…) — «тайно раздать деньги рабочим», «поговорить с редактором и предложить должность», «разведать планы Ложкина».
- В плане недели видно шанс и цену; `отменить N` — убрать действие и вернуть деньги.
- `0` или Enter — завершить неделю (внизу — сводка: что изменилось, ходы соперников, горячие точки). `1`–`7` — экраны (Я, Партии, Пресса, Журнал, Справка, Управление, Город).
- `внеси закон <текст>` — свободный закон. `отзыв <текст>` — отзыв автору (файл `saves/feedback.txt`, итог сессии — `saves/playtest_report.txt`).

## Живой мир (`Kocto/data/world/world.json`)

Всё настраивается в JSON, код только исполняет:
- **Соперники** (`nn_rivals.py`) — у Ложкина и Ворониной характер; каждую неделю они оценивают ситуацию и выбирают ход (агитация, медиа, атака на игрока, грязный приём, оборона). Атаки на них запоминаются — они мстят. Разведка показывает их планы на следующую неделю (экран 7).
- **НПС** — мэр, спикер, редактор реагируют на предложения (деньги, должность, давление, услуга, похвала) по своему характеру; незаконное при провале оставляет улики.
- **Слова запоминаются** — противоположная позиция по той же теме в течение 12 недель → газеты пишут о «переобувании».
- **События из настроений групп** — забастовки, протесты, петиции; горячая группа сильнее реагирует на действия.
- **Правосудие** — улики → следствие → задержание → суд (адвокаты, связи) → оправдание или срок → освобождение. Тюрьма не убивает сама по себе; смерть — от покушений при высокой угрозе.
- **Баланс** — пожертвования сторонников зависят от узнаваемости и доверия, у потолка рост замедляется, без действий узнаваемость забывается, выборы — счёт с весами и шумом.

## Настройки (`Kocto/data/nn/config.json`)

- `playtest_mode` — A/B и ревизия (по умолчанию выкл.).
- `enabled_writer` — НС-писатель (`nn_writer.py`); по умолчанию выкл., пока его тексты не проходят проверку качества. Тексты пишет шаблонный генератор из `data/text/templates.json`.

## Структура

Ядро: `models.py`, `systems.py`, `language.py`, `ui.py`, `main.py`. Модули: `nn_rivals.py` (решения соперников, без LLM), `nn_recognizer.py`, `nn_analyzer.py`, `nn_writer.py`. Весь контент — JSON в `data/`. Тесты — `tests/`.
