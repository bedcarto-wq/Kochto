# Выбор кампании и сохранения

В этой рабочей ветке добавлен новый запуск игры с выбором кампании. Это подключённая функция, но не завершение всего большого апдейта.

## Запуск

Windows: `Запустить.bat` или `Запустить_консоль.bat`.

Из исходников:

```bash
cd Kocto
python campaign_launcher.py
python campaign_launcher.py --console
```

`python main.py` остаётся старым режимом с единственным save.json. Для новой системы используйте campaign_launcher.py. Сборка Kochto.exe перенастроена на него; готовый новый exe ещё нужно собрать и проверить.

## Меню

- Новая игра — отдельная кампания, затем обычный ввод имени/возраста.
- Продолжить — последняя активная кампания.
- Загрузить — выбранная кампания.
- Удалить — с подтверждением; удаляется также резервная копия и память фраз этой кампании.
- Восстановить копию — с подтверждением возвращает предыдущий сохранённый этап.

Список показывает имя, игровую неделю, должность, время сохранения (UTC) и состояние. Погибшие персонажи остаются в списке, но продолжать их кампанию нельзя. Поражение на выборах не превращает сохранение в погибшее.

## Автосохранение

Начальное состояние сохраняется после создания персонажа. Далее — только после окончания недели. Изменения незавершённой недели, её очередь действий и закрытие окна сами по себе не обновляют контрольную точку. После повторного запуска вернётся начало текущей недели.

Перед записью новой недели хранится одна предыдущая контрольная точка. Запись — через временный файл и атомарную замену; ошибка записи не должна оставлять половину JSON. Повреждённый основной файл не копируется поверх исправного резерва. Восстановление требует отдельного согласия, не выполняется молча.

Имя персонажа показывается в меню, а файл получает безопасное независимое имя. Символы `?`, `:`, `/` и другие не ломают сохранение в Windows. Совпадающие имена создают отдельные кампании «Имя», «Имя (2)» и т.д.; автоматической перезаписи нет. Выбор «заменить одноимённую кампанию» пока не добавлен.

Старый save.json не удаляется и не импортируется автоматически. В меню показывается предупреждение, если он существует. Старые архивы и файл отзывов не затрагиваются.

## Проверки

Локально прошли 28 тестов хранилища, консольного меню и адаптера. Ещё 4 теста проверяют интеграцию с настоящими main.py/models.py/systems.py в CI: очередь без записи, сохранение после недели, состояние/генератор случайности, смерть и продолжение после поражения.

Оконное меню и новая Windows-сборка требуют отдельного ручного плейтеста. Не считать их визуальную проверку проведённой только по unit-тестам.
