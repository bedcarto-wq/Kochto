# Технические изменения — статус 0.8.8

Язык остаётся Python. Переписывание на Rust/C++ не заменяет исправление модели.
Текущий регион ограничен двумя городами, федерация — четырьмя; нет заявления,
что такой же проход выдержит сотни городов.

| Обсуждённое направление | Есть | Остаток |
|---|---|---|
| Симуляция / смысл / представление | world/civic/crisis_life; story; UI отправляет проверяемые команды | Разделить оставшийся большой world.py на вычислительные фазы без изменения порядка |
| Иерархия | Отдельные казны, правительства, выборы; scoped city IDs | Собственные верхние лидеры, отделения, кампании и полноценные полномочия |
| Разная детализация | НЕ реализована; все 4 города живут одинаково полно | LOD только с тестом независимости результата от камеры, не за счёт остановки фонового мира |
| Порядок времени | Локальные расчёты в каноническом порядке → общие потоки | Общая очередь команд/фаз и несколько RNG-потоков внутри города |
| Отдельные кризисы | crises.py + crisis_life.py, обычная экономика/проекты | Полные 50 направлений, статус в КРИЗИСЫ_50.md |
| Измерения | tools/benchmark_world.py: seed 88, 1/2/4 города, время, выделенная память, сейв/пакет, roundtrip | Время запуска окна, RSS процесса и профилирование GUI на машине игрока |
| Устранение повторной работы | Индекс когорт в операциях кризиса; дельты сокращают передачи | Dependency cache, пакетные UI-обновления и отказ от полного copy только по измерениям |
| Повторяемость | RNG каждого города, канонический порядок, целые жители/голоса | Фиксированная денежная единица всех подсистем и раздельные тематические RNG |
| Законы мира | Популяция/миграция, бюллетени, казны, эскроу, деньги, мандат, сохранения/камера тестируются | Полные налоги/банк/ресурсная экономика и инварианты LOD |
| Сейвы | Схема 6; bounded zlib федерации; checksum; атомарная запись; backup при миграции 0.8.7 | Раздельная долговременная история и потоковые крупные сейвы |
| Сеть | Авторитетный host; revision; дельта с base/result checksum; проверка всех путей/состояния; resync полным снимком | Автопереподключение/повтор команды с idempotency key; независимая камера игроков |
| Защищённый транспорт | НЕ реализован; HMAC не считается шифрованием | Отдельная задача TLS/доверия сертификатам; играть только с доверенными людьми через VPN |

Измерения headless относятся к этому окружению и размеру мира. Их нельзя выдавать
за гарантированный FPS, время запуска Windows или производительность всей страны.
Профилирование: `python -m cProfile -o world.prof tools/benchmark_world.py --weeks 26`.
Обычный запуск: `python tools/benchmark_world.py --weeks 26 --output benchmark.json`
из папки Kocto. Полные snapshots остаются для подключения, отклонённых команд,
восстановления и случаев, когда дельта оказалась больше снимка.
