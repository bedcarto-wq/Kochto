# «Город помнит» — ядро MVP

Отдельный пакет `gorod/`. Старый движок (`systems.py`, `main.py`, `ui.py`) **не тронут**.

## Запуск
```
cd Kocto
python -m gorod.ui_tk          # окно (Запустить_город_окно.bat)
python -m gorod.console        # консоль (Запустить_город.bat)
python -m unittest tests.test_gorod tests.test_gorod_v2
```

## Правила MVP
- 12 недель до выборов, 3 действия в неделю. После выборов игра продолжается (Game Over — только смерть; смерти в MVP пока нет).
- Город: рабочие (4200), пенсионеры (3100), предприниматели (1400). Соперник — мэр Ложкин. Председатель совета, редактор «Городского вестника». Газеты: «Городской вестник», «Голос улицы».
- Три спорных вопроса, у каждой группы своя позиция (−1..+1) и значимость вопроса:
  расширение завода, заморозка тарифов ЖКХ, сбор с торговли на ремонт дорог.
- 7 карточек действий: встреча, заявление, обещание (со сроком), инициатива в совете, интервью, охрана, огласка угроз.
- Фраза → **одна** карточка. Перед броском показано «Понято как …», шанс, цена и предупреждения. Лишние слова ничего не добавляют.
- Бросок: d100 + навык/3 против сложности; ≤5 — провал; запас ≥30 — блестяще.

## Что значит «город помнит»
- Повтор той же позиции даёт всё меньше (1, ½, ⅓ …), а газеты пишут «повторяет одно и то же».
- Смена позиции снижает доверие всех групп, и все открытые обещания с противоположной позицией срываются.
- Обещание без инициативы в срок срывается: группы, которым оно нравилось, теряют поддержку и доверие. После каждого сорванного обещания ваши слова для этой группы весят вдвое меньше, а встречи с ней сложнее.
- Соперник читает журнал: вспоминает сорванные обещания и развороты или едет туда, где вы собираете больше всего голосов.
- Каждая газета выбирает факт недели по своей повестке. Угол подачи зависит от её отношения к герою новости и от исхода. Шаблон берётся наименее использованный.

## Выборы
Голоса в группе = численность × явка. Доля кандидата = П×(0.5 + доверие/100) ÷ (П×(…) + поддержка соперника). Итог показывается с раскладкой по группам.

## Контракт
- `engine.load_data(dir=None) -> dict`. При ошибке данных — `DataError` с адресом поля.
- `engine.new_game(data, name, skills{charm,eloquence,cunning}=90, gender "m"|"f", seed=None) -> State`.
- `parser.parse(data, text) -> Parse(card|None, guessed, alternatives, notes)`.
- `engine.missing_slots / preview(state, data, card)` — без побочных эффектов.
- `engine.perform(state, data, card) -> {roll,total,difficulty,tier,facts}`. Если ход невозможен — `RuleError`, состояние не меняется.
- `engine.end_week(state, data) -> {week, income, world_facts, articles, election}`.
- `engine.save_game / load_game` — JSON с `schema_version`, зёрнами недель (схема F) и полным журналом фактов.

## Угрозы и смерть (MVP 2)
- Решения против сильных интересов наживают врагов: запрет расширения завода → владелец завода; сбор с торговли → хозяева рынка; заморозка тарифов → управляющая компания. Публичная позиция даёт 40% угрозы, принятое решение — 100%. Проигрывающий соперник тоже может давить («окружение мэра»).
- Угроза 0–100 затухает на 1,5 в неделю. На 30 и 60 приходит предупреждение с указанием источника.
- Выше 40 возможны покушения: шанс в неделю = (угроза − 40 − 15×охрана) / 200. Исход: провал (доверие растёт), ранение (−1 действие на 2 недели) или гибель. **Гибель = конец игры.**
- Защита: «нанять охрану» (до 3 уровней, 40 в неделю за уровень; нечем платить — охрана уходит), «заявить об угрозах» (снижает угрозу; если давит окружение мэра, бьёт и по сопернику; без реальной угрозы — паника и минус доверие).

## ИИ
- **Понимание фраз** (`nlu.py`): стеммер, наивный Байес, исправление опечаток (≥6 букв, расстояние 1). Модель обучается при загрузке на `data/train_phrases.json` (165 фраз, точность leave-one-out 0,80). Словарь основ главнее. Классификатор нужен для свободных формулировок («посидеть с бабушками на лавочке») и для выбора одного действия из нескольких. Источник и уверенность показываются игроку.
- **Соперник** (`rival_ai.py`): планировщик по полезности. Для каждого хода считает изменение прогноза выборов: встреча (с усталостью от повторов), напоминание о промахах кандидата из журнала, перехват выгодной позиции (один раз на вопрос, верят вполовину), а если проигрывает с 6-й недели — компромат или давление. Причина хода пишется в факт.
